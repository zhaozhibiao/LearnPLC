# 周期轴诊断记录器

可选的独立诊断通道。每个主站循环记录同一接收过程映像中的位置反馈、速度反馈、内部位置需求 6062、有符号跟随误差 60F4、转矩 6077，以及本周期处理前后的目标、周期编号、计划/实际单调时钟、总线有效性、运动编号、状态字和错误码。

本目录新增代码采用 [MIT](LICENSE)，允许商业使用；不改变既有运动核心、IgH 等组件各自的授权。

## 数据与实时边界

- 6062、60F4 按 Int32 解码；6077 按 Int16 解码。原始整数写入 CSV，不经过 Float32。
- 构造阶段分配并初始化全部内存。`capture` 只读取 PDO 并写入预分配数组，不分配内存、不加锁、不做文件 IO、不写控制量。
- 默认 60000 周期，上限 120000。容量用尽停止追加，递增 dropped；不等待、不覆盖早期记录，也不改变轴状态。
- 主循环与工作线程停止、主线程退出实时调度后，才导出 CSV。输出文件使用独占创建，不覆盖既有文件，不跟随末级符号链接。SIGKILL、断电或异常直接退出时，内存记录可能无法导出。
- 当前 CLI 限定一个工程轴。未传 `--axis-trace-csv` 时不创建记录器。开启时要求诊断 PDO 键、方向和位宽准确，缺项则在协议服务启动前失败。
- 专用配置在原有 TxPDO 1A00 五项后附加三项，共八项；RxPDO 不变，原运动算法和保护参数不变。

## 周期含义

接收 PDO → 保存处理前目标 → 原轨迹与保护处理 → 记录本周期新目标和接收输入 → 发送 PDO。

`previous_target_raw` 是本次轴处理前的输出映像目标；`sent_target_raw` 是处理后的待发送目标。它们与接收输入列放在同一主站周期记录中，不代表电机内部各对象在完全相同的物理时刻采样。还须考虑驱动器滤波、同步相位、传输延迟和回零偏移。

分析时首先过滤 `bus_ready=1`，再用状态字检查是否使能，不能把 PREOP/SAFEOP 数据当作有效运动反馈。`cycle_error` 是现有核心的比较值，`drive_error_raw` 是驱动器返回值，二者不能在没有单位、时序确认时直接等同。转矩原始值的厂家单位为 0.1% 额定转矩；原始位置、速度仍需按该工程的电子齿轮和机械参数换算。

CSV 前三行记录格式、容量和 dropped；其余是表头与数据。`scheduled_ns` 的增量表示计划周期，`monotonic_ns` 表示实际唤醒采样时间，应检查二者差值及循环耗时日志，而不能只凭行数宣称实时性能。

## 可复现构建

已验证的精确源码快照位于项目 `artifacts/cyclic-trace-20261023/source-snapshot.tar.gz`，包含既有诊断基础修改与本次叠加；不是生产安装。该快照已应用记录器，不要再次运行安装器。

Linux 解包到独立目录后，使用原设备已安装的 IgH 和 JSON 开发包构建：

```sh
cmake -S src/EcMotion.Igh -B build -DECMOTION_IGH_ROOT=/opt/etherlab -DECMOTION_IS620N_PROFILE=ON -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build -j2
ctest --test-dir build --output-on-failure
```

`install_trace.py ROOT` 用于将本目录叠加到本轮精确诊断基础树，校验 main.cpp 与 CMake 的 SHA256 和集成锚点，拒绝其他修订或重复应用；它不操作设备或服务。先前仅含发布补丁的源树可能缺少前几轮的周期峰值诊断字段，不能假定与该基础树等同。源码快照是完整复现依据。

`prepare_trace_config.py ROOT` 生成独立、绑定机器/IO 文件哈希的 `config/axis-trace-ethercat.json`，拒绝覆盖现有配置。

新增 CLI：

| 参数 | 含义 |
|---|---|
| `--axis-trace-csv PATH` | 开启记录；停机后导出到尚不存在的文件 |
| `--axis-trace-capacity N` | 记录周期数，1..120000，默认 60000 |
| `--axis-trace-prefix Axis1Drive` | 对应 PDO 键前缀，默认 Axis1Drive |

设备验收使用 `verify_disabled_trace.py ROOT`。它需要设备访问与实时调度权限，在独立临时服务启动候选，仅发送 Hello/ReadSnapshot，不获取控制权、不复位、不使能、不回零、不运动。结束时停止候选并验证 CSV 和最终状态。它面向本轮现场目录，不应作为通用自动部署服务。

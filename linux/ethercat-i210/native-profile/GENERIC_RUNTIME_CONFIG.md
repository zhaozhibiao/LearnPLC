# Generic EtherCAT runtime configuration (schema 1)

The native runtime accepts `--ethercat-config /path/ethercat-runtime.json`. Without that option it retains the generated legacy topology, including the IS620N commissioning profile when selected at build time. `--validate-ethercat-config /path.json` validates the EtherCAT document and exits before accessing the master. Bound bundles require explicit `--machine-config` and `--io-map` arguments; companion hashes, schemas, axis topology, motion adapter construction, master/axis cycle agreement, axis-owned IO exclusion, and IO layout binding are checked before returning success. A topology-only invocation remains available for unbound documents when neither companion path is supplied. It deliberately does not start the cyclic task or read devices.

Required fields: `schemaVersion` (1), `readyForRuntime` (true), `blockers` (empty array), `cycleTimeNs` (100000..1000000000), `topologyFingerprint` (nonempty), and `slaves`. Each slave requires `position`, `vendorId`, `productCode`, `revisionNo`, `name`, `dc`, `moduleIdents`, `startupSdos`, and `pdos`. All integer fields must be JSON integers, without narrowing or negative values.

PDOs use `direction` (Rx/Tx), `syncManager`, `index`, and `entries`; entries use `index`, `subindex`, `bitLength` (1..64), and globally unique `key`. Each slave's PDO object addresses and PDO indexes must be unique. PDO padding (index zero) is explicitly unsupported and fails validation. PDOs for one sync manager must be contiguous. Optional `syncManagers` contains `index` (2..15), `direction` (Rx/Tx), and `watchdog` (Enable/Disable/Default). If absent, managers 2/Rx/Enable and 3/Tx/Disable are inferred.

DC with `enabled:true` requires `assignActivate`, `sync0CycleNs`, `sync0ShiftNs`, and `sync1CycleNs`. Sync0 cycle must equal the master cycle. Startup SDOs contain `index`, `subindex`, and nonempty byte-array `data`; optional `completeAccess:true` requires subindex zero, and optional `transition` must be PS. Direct startup writes to motion control/target indexes 6040/607A/60FF/60B1/6071 are rejected. Per-axis homing SDOs retain their existing separate commissioning validation and are scheduled after generic startup SDOs.

Bounds: 4 MiB input, 64 slaves, 1024 total PDOs, 4096 total entries, 255 module identifiers per slave, 256 startup SDOs per slave, 1024 bytes per SDO, 65536 total startup SDO bytes. Owned strings and vectors are fully materialized before entering the cyclic loop. Axis mappings are checked against slave ownership and the existing CiA402 ABI widths and directions before requesting the master. Online vendor/product/revision matching is exact.

Optional paired `machineSha256` and `ioMapSha256` bind the exact serialized machine and IO files. When present, the normal startup path checks both before parsing them and before requesting the master. Host-generated bundles always provide both. Hello reports `ethercatTopologyFingerprint` directly from the selected native configuration, initialized before protocol threads; it does not substitute the derived IO catalog fingerprint.

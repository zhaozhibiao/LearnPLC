# IS620N 正转1.5圈、等待2秒、反转1圈

在工程站打开 `TurnTest.stproj`。`Main.st` 是可阅读的同内容副本；实际工程源码由 MCP `source_write` 写入、`project_save` 保存。项目创建/修改/编译调用记录见 `mcp-final-evidence.json`，编译包位置与身份见 `build-final-evidence.json`。

## 动作与参数

单次启动后：使能 → 以当前位置建立临时原点 → 正转1.5圈 → 实际到位后等待2秒 → 反转1圈 → 停止并撤使能。最终位置是测试起点 +0.5圈，**不是返回起点**。

沿用已有已验证的 IS620N/ISMH1-10B30CB-U230Z 单位换算，工程轴名 `IS620N`、核心轴名 `Axis1`，单位 `rev`。临时原点沿用已配置的方法35，不寻找原点开关，不自动清除驱动器报警。

默认速度0.01圈/秒，即0.6转/分钟；按2.5圈总行程计算约250秒，加等待2秒及加减速、回零和撤使能开销，约4分12秒以上。总流程超时为300秒。仅在启动时锁定目标、速度、公差和临时原点选项，运行中修改这些输入不会改变当前动作。

独立测试工程的软件限位改为±2圈，才能容纳+1.5圈目标。**当前设备仍是原±1圈组态，本次没有应用新组态、下载或激活测试程序。** 实际试转前，需要通过硬件页确认并应用该测试组态，再下载匹配程序；不能只将旧程序的位置常量改成1.5。上述扩大范围只适用于此前已确认空载且固定的测试电机，不能直接移植到其他机械。

## 启动与观察

默认 `RunOnce=FALSE`、`ParametersConfirmed=FALSE`，冷启动不会发出使能、回零、定位或撤使能指令。确认对应组态已实际应用、轴和单位正确后，设置 `ParametersConfirmed=TRUE`，再将 `RunOnce` 从FALSE切换至TRUE。即使启动信号保持TRUE，也只执行一次。

观察 `State`、`Active`、`ActualPositionRev`、`Passed`、`Failed`、`OutcomeUnknown`、`DiagnosticCode` 和 `CompletedTests`。`CancelTest=TRUE` 或运行中撤销参数确认将进入停止、撤使能流程；反馈丢失和超时不会报告成功，停止/撤使能无法确认时锁存 `OutcomeUnknown`。

| State | 含义 |
|---|---|
| 0 | 等待单次启动 |
| 10 / 20 | 等待使能 / 临时原点 |
| 30 / 40 / 50 | 正转 / 到位后2秒等待 / 反转 |
| 80 / 90 | 停止 / 撤使能 |
| 100 | 成功完成 |
| 900 / 999 | 失败 / 状态未知 |

再次测试需先将 `RunOnce=FALSE`，确认真实轴已停止、撤使能，再用 `Acknowledge` 清除程序结果；不会自动重试。程序停止指令属于普通控制停止。

## 验证

已通过真实 MCP stdio 客户端创建与保存，43个工具发现正常，工程检查和真实 STruC++ 编译通过。对同一包的生成 C++ 在 Linux 编译，并以纯内存模拟反馈验证13个场景：冷启动、未确认、正常顺序、非零起点、离线、初始运动、非数位置、非数位移、启动前取消、回零失败、等待中取消、反馈丢失、超时。

测试断言包括首个定位目标为起点+1.5、第二个定位目标为起点+0.5，且反转请求在正转完成至少2秒以后发出；完成后只撤使能一次，保持启动信号不会再运行。对应 `test_sequence.cpp` 不含 socket、EtherCAT 或现场运动调用。这些验证证明程序逻辑，尚不代表新行程已在电机上验收。

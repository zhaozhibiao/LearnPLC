# 下载与应用程序

生成当前工程的有效程序包后，点击顶部“下载 / 应用程序”。工程站依次上传、在 Linux 编译并检查运行后端；这段时间不会停止或替换原程序。

编译成功且满足应用条件后，显示“下载并应用程序”提示：目标设备、当前运行状态、停止原程序、重启 Runtime 核心、在线监视断开和完成后保持停止。点击“重启核心并应用”，工程站会再次检查设备活动版本及状态，然后自动停止原程序（如有运行）、应用新程序并核对设备确实处于停止状态。此后点击顶部“▶ 运行”才开始执行，不自动启动。

点击取消只保留 Linux 编译结果，不执行停止或切换。之后可使用“应用已编译程序”，无需重复上传与编译，但会重新核对设备并显示重启提示。若同一程序已经是活动版本，工程站显示真实运行/停止状态，不重复重启核心。

确认期间修改工程或连接目标、外部改变设备活动版本或运行状态，会拒绝继续操作。未登记基线时先在“下载与激活”页登记。编译失败、运动后端未就绪、离线机械参数尚不能应用等情况，不会进入停止/切换流程。通信中断或激活结果不明会禁用运行控制并提示先刷新真实状态，不自动重试或恢复运行。

当前固定 OpenPLC 后端切换程序需要重启 Runtime 服务，属于停止后下载，不提供在线热替换。本轮仅修改上位机串联流程，设备端仍使用原有摘要校验、备份和事务恢复逻辑；没有远程修改或启停服务。

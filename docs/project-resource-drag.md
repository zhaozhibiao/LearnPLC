# 工程树资源拖放

关闭旧工程站窗口后，使用根目录“启动ST工程站.cmd”重新打开。

1. 打开目标程序或功能块，保持中央代码框显示该源文件。
2. 从左侧工程树按住左键拖动函数或功能块，到完整执行语句行松开。拖动不会切换目标文件，普通单击仍打开定义。
3. 函数自动生成具名输入/输入输出参数、返回值变量和调用。功能块自动生成唯一实例；当前程序有直接同类型的本地实例时，可选择创建新实例或复用。输出通过实例字段读取，调用后附有字段提示。
4. 全局变量资源展开后，拖动具体变量到表达式的空白位置，插入变量名；遇到本地同名变量遮蔽会拒绝，避免引用错误对象。声明带 AT 地址的全局变量也能在树中显示。
5. 数据类型资源展开实际类型名称，拖到变量声明区的完整声明行，生成唯一名称的变量声明；不能拖到执行代码区。
6. 调用中自动生成的是参数占位变量，必须按工艺要求替换或赋值。实例与占位变量、调用可用一次 Ctrl+Z 一起撤销。

修改全局变量或类型源声明后，工程树成员随之更新。程序仍由周期任务绑定，不作为函数拖入。功能块不能插入无持久状态的函数中；注释、字符串、跨行语句中部、失效引用和不完整接口会明确拒绝。

源代码仍由独立 ST 编译器检查。拖放保留接口中的完整类型，但不能扩大编译器本身支持的语法：当前 0.7.0 编译器拒绝 `STRING[20]` 形式，普通 STRING 已通过实际验证；内嵌结构参数应先定义为独立数据类型。编译失败会显示源文件诊断，不生成可下载候选。

验证：完整构建零警告/错误；核心插入、真实工程树手势和路由 Drop、一次撤销、实例复用、成员更新及旧右键/指令库/在线协议回归通过。独立 ST 编译器实际编译拖放生成的函数（含 Result 输入）、数组、STRING、输入输出参数、功能块、全局变量和自定义数据类型，并生成候选包。未下载、激活或运行设备程序。

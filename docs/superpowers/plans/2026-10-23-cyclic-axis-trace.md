# 周期诊断采集实施计划

**Goal:** 在独立候选加入可复现的 1 ms 有界轴记录器，并在未使能设备上验证。

**Architecture:** 专用有符号 PDO 解码 + 预分配记录数组 + 停机后 CSV；独立配置追加三个 TxPDO 输入，不改轴算法和保护。

**Tech Stack:** C++20、现有 PdoImageView、IgH、Python、CTest。

- [x] 在目标普通用户构建自测，确认缺少记录器时失败。

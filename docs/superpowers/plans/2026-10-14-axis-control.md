# 基础轴控实施

1. Native/ST：实现固定64轴图像、基础/读取功能块、非阻塞通信与生命周期；先验证边沿、Busy、抢占/Stop锁、错误和扫描心跳。仅新 tools/axis-bridge 文件。
2. Linux axis worker：v4协议客户端、清单/能力文件、独占租约、命令/实际反馈关联、控制停止及扫描超时；协议假端与真实原项目仿真验证。仅新 linux/axis 文件。
3. Core/Toolchain：检测绑定基础轴类型，固定常量与清单，编译适配（可同时保留路径库）、依赖库存和构建身份；无轴程序保持旧包与源身份。
4. UI/部署：有工程轴时资源库显示真实调用；现有普通检查编译包含库；Linux候选生命周期/后端能力门禁，基础轴和轴控周期门禁各自明确，不把模拟标为物理。保留原布局。
5. 核心、原生、Python、真实 ST/隔离 Runtime 编译及原项目仿真集成测试，审查与文档。无实体轴运行、无服务启停。

用户已明确要求实施，按批准架构连续执行；独立子任务使用 subagent-driven-development 技能，主任务负责整合与最终核验。

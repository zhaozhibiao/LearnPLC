# 在线监视页面精简

用户目标：移除普通操作中无用的技术信息，优先显示变量、实例和趋势。

## 设计与实施

1. 开始/断开监视集中显示；状态仅展示连接情况、更新时间和变量数量，失败时仍保留具体原因。
2. 原始 Runtime 状态和日志查询移到“连接与工具 → 设备诊断”，默认折叠。
3. 变量/趋势占用剩余空间，可调左右比例；采样刷新保留选择和实例展开状态，异常样本使用中文状态而非旧数值。
4. BOOL 写值放在可展开区域，窄窗口自动换行和滚动。保留原有身份校验、样本有效性、逐次确认、单次发送及后续读回验证。
5. 不调整设备程序或运行状态，不引入设备写入。

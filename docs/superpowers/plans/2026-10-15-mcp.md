# ST Workbench MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a local stdio MCP server for saved ST projects, engineering configuration, compilation, deployment and explicitly configured EcMotion control.

**Architecture:** A new .NET executable reuses existing libraries. An isolated Linux JSON-lines motion gateway owns its own EcMotion connection and lease; it never impersonates a PLC scan. All project writes use drafts, revision checks, workspace confinement and atomic ProjectStore persistence.

**Tech Stack:** .NET 10, official ModelContextProtocol SDK 2.2.0, existing Core/Toolchain/Motion libraries, Python 3 standard library, SSH.

## Task 1 — Linux motion gateway

Files: linux/mcp/motion_gateway.py, linux/mcp/test_motion_gateway.py, linux/mcp/README.md, linux/mcp/LICENSE.

- [x] First write protocol/state tests for readonly startup, lease conflicts, axis bounds, expiry, repeated operation IDs, stale feedback, matching MotionId, physical Home AppliedCycle, Stop preemption, EOF teardown and unsupported continuous paths. Run `python -m unittest discover -s linux/mcp -v` and observe missing implementation failure.
- [x] Implement a JSON-lines request loop on stdin/stdout with independent polling/deadlines, import validated existing axis protocol/manifest helpers, and make no connection except the explicit configured socket. Envelope `{requestId, action, ...}`; response `{requestId, success, state, ...}`. Allowed actions: capabilities, status, acquire, release, execute, operation, stop. Parameters never select another socket or manifest. Private lease token stays inside the process. Execute accepts a unique operationId, axis logical name, kind Enable/Disable/Reset/Home/MoveAbsolute/Jog, finite position/velocity and bounded durationMilliseconds. Device-side gateway owns operation lifetime and stops/relinquishes on expiry and disconnect.
- [x] Re-run protocol tests and isolated original simulator end-to-end. Report exact physical capabilities refused. Review spec then code quality before integration.

# 常驻工程服务、统一编译与分范围上下载

本设计依据用户最新四点要求，替代上一版程序下载自动应用硬件的交互。方向固定：上传（上载）为 PLC → 工程站，下载为工程站 → PLC。工程站内部向设备传送文件的网络过程不再被命名为用户操作“上传”。

## 1. 在线连接

推荐新增独立于 PLC 程序和运动核心生命周期的普通用户常驻工程服务，提供固定 HTTPS 端口；建议默认 18445，安装前检查占用。备选是直接使用现有 OpenPLC HTTPS 与调试 WebSocket：改动小，但其服务重启仍导致管理连接断开，因此选择独立工程服务。

工程站只需首次建立受信任的设备会话，之后在线监视、程序身份读取、日志和工程传输都经该服务完成，不再每次启动 SSH 或查询 SSH 身份。设备身份认证与工程一致性是两层检查：复用既有设备证书校验，配对授权保存在系统凭据存储；日常在线自动使用会话，不弹 SSH 验证。程序切换后保留管理服务，重新核验后恢复监视，不自动恢复变量写入。

在线门禁比较设备实际活动程序与本地工程的源程序身份，以及调试符号身份、变量布局和目标配置身份。程序一致且符号有效即可在线，不要求每次重新生成新候选，更不能仅因设备处于停止状态拒绝只读在线。工程变化、设备程序切换、反馈过期时立即失效旧值和写权限。变量写入保留现有单次确认和精确身份检查。服务不公开任意 shell、路径或系统服务操作，复用当前部署协调器及受限硬件代理。

## 2. 编译与候选包

主按钮统一为“编译”，执行工程检查、ST 编译和候选包生成；F7 同样执行，不再要求另点“生成候选包”。编译成功表示本地代码和设备候选完整生成，明确区分目标 Linux 编译状态。

点击“下载程序”自动捕获当前工程快照，检查、编译并生成匹配候选；已有完全匹配的编译产物可以复用，过期产物不得用于下载。目标端 Linux 编译保持在程序应用前。编译失败、工程或连接目标变化时不进行后续写操作。取消编译能中止全部构建步骤；只编译不改变 PLC。

## 3. 左树决定上传／下载范围

| 左树当前资源 | 上传按钮 | 下载按钮 |
| --- | --- | --- |
| 程序、函数、功能块、数据类型、全局变量、任务、路径 | 上传程序 | 下载程序 |
| 硬件、从站、IO 映射、轴配置 | 上传硬件 | 下载硬件 |
| 网络组态 | 上传硬件组态的网络描述 | 下载硬件组态；不自动修改管理网卡 IP |

程序范围是完整 PLC 应用，包括相互依赖的 POU、类型、全局变量和任务，不将单个函数误当可独立运行的 PLC 应用。按钮文案明确当前范围；页面或选择变化后更新。上传先展示设备身份及内容摘要，可保存为独立工程；应用到当前编辑工程时执行本地未保存修改保护，不静默覆盖。上传不停止 PLC、不应用设备参数。

新增库存校验覆盖的工程归档，保留原始 ST、对象元数据、任务、源程序身份、调试映射、路径 ID/版本与完整回读所需的工程元数据。程序上传取设备实际活动版本，不能误取最近暂存但未激活的候选。硬件上传取实际已应用版本并验证加载指纹，同时提供对应已保存工程组态；不能以候选离线配置冒充实机组态。

旧设备程序若没有源工程归档，只能读回其真实身份和已保存的可验证元数据，明确提示“该版本未保存源工程，无法还原 ST”；不伪造源码、不从编译 C++ 猜测还原。下一次使用新版工程站下载后，才保证该版本完整上传。若本地存在相同身份的源工程，可核验后使用本地副本，但须明确来源。

## 4. 分离下载的实际行为

下载程序只应用 PLC 应用，不隐式调用 configuration-apply 或 hardware-apply，不更改轴清单、限值、IO 或物理总线。下载前比较程序依赖的实际物理组态、轴映射、参数及周期；任何必需项不同则展示差异并提示先“下载硬件”。检查失败不停止当前程序。仅程序的源身份变化不能被误判为硬件不同。

下载硬件独立生成、传送并应用硬件/IO/轴清单，不切换 PLC 程序。它不依赖 ST 编译成功；非法 ST 不应阻止修正硬件配置。若需要重启运动核心，确认中说明影响并保留停稳、撤使能、安全输出和反馈检查。硬件更新后原程序不兼容时保持停止，禁止自动恢复或手动启动；程序仍兼容时按实际影响明确报告状态，不自动使能轴。

程序应用前一次提示 Runtime 重启及在线断开影响。硬件已经匹配时，原来运行的程序在新身份核验后恢复运行，原来停止的保持停止。所有结果不明均不自动重试；失败保持明确的实际或未知状态。

## 5. 验证与实施顺序

先实现传输范围及编译语义，增加工程归档/回读，再实现常驻服务与会话、切换桌面在线和传输，最后部署到现有 Linux 设备作只读核验。常驻服务采用项目已有技术栈及商业可用的自有实现，不新增未审核的强制许可证依赖。

必须覆盖：编译一键产包、下载自动构建、无效 ST 不阻断独立硬件下载；左树反复切换和按钮范围；上传只读及未保存保护、活动版本/候选版本区分、旧版本无源码；在线不调用 SSH、设备/源码/符号变化立即失效；硬件不一致时程序下载没有停止或修改组态操作；硬件更新失败与原程序不兼容时不启动。部署及测试不自行触发电机运动。

本文件为可评审设计；尚未更改上述功能的实现。

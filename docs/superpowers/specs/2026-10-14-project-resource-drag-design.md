# 工程资源拖放

用户已批准上一轮说明中的行为，并要求执行。保持现有布局和下载逻辑，在工程树中直接拖入函数、功能块、全局变量和数据类型。

- 函数从源声明读取接口，生成具名参数和返回值变量；占位信号明确要求用户修改。
- 功能块默认创建唯一实例；存在直接同类型的本地实例时提供创建/复用选择。实例与调用一次撤销。输出可通过实例字段访问。
- 全局变量节点展开为实际变量子节点；拖动具体变量插入引用，拒绝被本地同名变量遮蔽的引用。集合不作为一个变量调用。
- 类型资源展开实际 TYPE 名称；拖入完整变量声明行生成唯一变量，只接受声明区域。
- 拖动工程树时不切换当前目标源文件；普通点击、右键和键盘选择仍能打开源文件。
- 拒绝注释、字符串、跨行语句中部、失效资源和不支持的接口。程序仍由任务调用，不生成普通函数调用。
- 全部编辑使用同一撤销组，保持现有在线身份失效机制。纯核心、实际路由事件与独立 ST 编译验证。

实现采用词法接口读取及既有插入机制，不引入第二个编辑器或编译后端。源文件仍为权威接口，拖放时重新读取。

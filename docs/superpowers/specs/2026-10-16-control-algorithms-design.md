# 常用 ST 控制算法库设计

状态：用户于 2026-10-16 确认“其他范围照上面”，已批准实施。与底层通信分成两个独立实现单元；共用工程、资源库、编译打包和 MCP 集成方式。算法源码自研并采用 MIT，不引入闭源或来源不明的控制库。

## 运行方式

推荐以 ST 功能块作为权威实现，在 PLC 周期中执行，可由原编辑器或任意已连接 MCP 的模型声明实例并调用。编译器自动注入实际使用的库，候选包记录库版本及摘要；不只提供代码片段或仅在上位机计算。

另两种方案是把算法放到上位机（控制依赖通信时延），或全部放在原生扩展中（调试和可移植性成本更高）。本轮采用有界 ST 实现，使用真实编译产物验证数值行为，不用另一语言的参考公式替代产品代码测试。

## 初始功能目录

| 模块 | 主要能力 |
|---|---|
| WB_PID | P/PI/PID 参数组合，正反作用、输出限幅、积分抗饱和、测量微分及滤波、前馈、手自动无扰切换、复位 |
| WB_INCREMENTAL_PID | 增量式输出、积分/输出约束、状态初始化和模式切换 |
| WB_CASCADE_PID | 主副回路、主回路限幅、内环手动时的外环跟踪、可明确设置的主副采样关系 |
| WB_ONOFF | 带滞环的两位控制与最小通断时间 |
| WB_LOW_PASS | 一阶低通、时间常数、初始化和复位 |
| WB_MOVING_AVERAGE | 有界窗口滑动平均，窗口变更及预热状态 |
| WB_MEDIAN | 有界奇数窗口中值滤波 |
| WB_KALMAN_1D | 标量估计、过程/测量噪声和初值协方差检查 |
| WB_SLEW_RATE | 独立上升/下降速率限制、跟踪与复位 |
| WB_LEAD_LAG | 超前滞后补偿，明确离散化及状态初始化 |
| WB_INTEGRATOR | 带复位、保持、限幅的离散积分 |
| WB_DERIVATIVE | 带滤波的微分，避免初始阶跃冲击 |
| WB_SCALE | 原始量到工程量线性换算、限幅、无效量程诊断 |
| WB_DEADBAND | 明确零区及回差语义，边界行为一致 |
| WB_TIME_PROPORTION | 时间比例/PWM 输出、占空比限幅和周期状态 |

这些模块与现有 TON、计数器、逻辑及数学指令共存，不能用同名实现覆盖上游库。自动整定、模糊控制、MPC 等更复杂控制不含糊地列入“已完成”；如后续需要，分别定义和验收。

## 参数与数值契约

统一采用明确工程单位及 LREAL 计算；每个实例保存自身状态。时间参数使用秒，控制采样周期显式输入并由资源模板根据已配置周期填入。名义任务周期不能冒充实时实测间隔；调用者可以提供经验证的实际采样间隔。

PID 主接口使用并联形式：输出为 Kp×误差 + Ki×误差积分 − Kd×测量微分 + 前馈。若输入/输出工程单位为 X/Y，三项增益单位分别是 Y/X、Y/(X·s)、Y·s/X；与 Kp/Ti/Td 的换算为 Ki=Kp/Ti、Kd=Kp×Td，不能把两种调参定义混用。方向通过显式参数选择；导数作用于测量值，滤波及前馈单独定义。输出上、下限及积分抗饱和方式固定文档与实现，不在饱和期间继续无界积累。

手动时输出跟踪手动值，切回自动按实际输出初始化状态，避免人为台阶。复位和首次启用的输出、滤波初值及积分初值写入每个模块说明。串级主回路跟踪副回路可接受设定值；副回路未运行时不能让主回路继续积分。

检查 NaN/Infinity、零或负采样周期、反向上下限、无效时间常数、噪声协方差、除零和中间数值溢出。错误时 Error/ErrorID 置位，数值块保留最后有效的有限输出，首次出错使用有界初始化输出；两位/PWM 块错误时采用显式故障输出参数，默认 FALSE。错误、禁用、保持和复位的状态演变分别定义，不能静默产生 NaN。功能块名称、参数类型、默认值和错误码在实现计划与接口文件中统一。

所有循环和缓冲有明确上限；滑动平均采用有界环形缓冲，中值使用小窗口。算法运行不做系统调用、网络或文件 IO。PWM/时间比例输出分辨率受 PLC 周期限制，不能宣称具有独立硬件 PWM 的频率精度。

## 工程集成

右侧增加“控制算法”分类，拖入时生成正确的有状态实例和参数声明，沿用一次撤销、名称避重与函数内状态限制。函数、块、全局变量的现有拖放功能保留。

算法模块通过同一库定义提供 ST 接口提示、MCP 目录和示例。使用算法会改变候选身份，编译和程序包包含确切算法源码及通知；无算法旧工程不改变库输入和历史身份。通信与轴控组合使用时，算法仍在 PLC 扫描中计算，网络只交换数据。

## 验收

先编写参考输入/输出向量及不变量，再运行真实 ST 生成代码。覆盖 PID 阶跃响应、正反作用、输出饱和后恢复、手动/自动切换、复位、采样变化、前馈、积分/微分边界与串级状态跟踪。

滤波覆盖稳态增益、噪声抑制、窗口预热/变更、脉冲、复位与非法参数；量程/限幅/斜坡覆盖边界和不同周期；标量估计覆盖协方差边界与收敛。以固定种子运行有界随机输入，断言输出始终有限且满足已配置限幅。

增加资源库拖放与撤销、MCP 库发现、独立编译、候选打包和 Linux 行为测试；通过一阶过程模型验证闭环，不连接真实加热器或实体执行机构。交付 ST 实现、接口手册、整定参数单位说明、示例工程、测试证据和 MIT 许可。

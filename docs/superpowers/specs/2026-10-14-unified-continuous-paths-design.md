# 同一工程内的连续路径加工

用户要求：保留 ST 工程站的布局和操作逻辑，复用 EcMotion 实时轴控核心，但不引入第二套上位机、第二套工程配置或第二套运动流程。复现 DXF 导入、路径预存和程序调用；执行采用连续加工轨迹，而不是逐点精确停止。本文件是接入设计，当前不代表功能已经实现或实机通过。

## 用户看到的完整流程

1. 工程树增加“路径资源”，右键导入 DXF、打开、属性、生成新版本、删除。原 ST、任务、硬件、连接、下载、在线布局继续保留。
2. 路径资源在现有中央工作区打开编辑页：显示原图及加工轨迹、轮廓列表、DXF 单位/缩放、轴组、偏移、加工速度、加减速度、跃度和轮廓容差。路径之间不自动连线；未定义进退刀、抬笔/落笔或跳转行为时不能将不连续轮廓当成一条加工路径。
3. 检查通过后预存为工程内不可变版本。保存工程携带路径资产和导入参数，重新打开、备份或换电脑不会丢失。Linux 预存结果记录明确 ID、版本和内容摘要；上传路径不启动运动。
4. 右侧资源库列出当前工程的路径，可拖入 ST 生成绑定该路径的功能块实例和调用。PLC 参数是工程路径引用，不要求操作者手抄 DXF 文件路径或服务器数字 ID。
5. 原“检查 → 生成候选包 → 下载/Linux 编译 → 显式激活 → 运行”流程同时检查路径依赖。任何引用路径缺失、几何摘要或轴映射不一致、连续执行能力不支持时，拒绝就绪和激活。已经预存的未修改路径复用，不重复导入。
6. ST 变量旁显示 Execute、Busy、Done、Error、ErrorID、Progress 等真实状态；路径编辑页显示同一个执行编号和轨迹进度。界面不直接代替 PLC 扫描推进轨迹。

## 一个资源模型，两层执行

工程是轴别名、轴组、路径绑定和参数的唯一配置来源。EcMotion 服务中的实例是由工程部署生成的执行资产，不是另外维护的工程。工程本地 ID 与服务器分配的数值 ID 显式关联；名称不是执行身份。ST 符号绑定明确版本，服务不能以“最新版本”静默替换已经运行的引用。

ST 周期中运行非阻塞的功能块状态机：Execute 上升沿只提交一次请求，随后的扫描读取同一请求的反馈。后台桥接处理本机 IPC，服务实时循环按自身总线周期执行连续轨迹并返回进度。队列有上限；周期内不等待 IPC、不解析 DXF、不进行无界内存分配。Done 只在实际执行反馈完成时成立，受理和加入队列不代表完成。PLC 停止、扫描超时、租约过期和程序替换要联动取消/受控停止，不能由通信线程的心跳掩盖 PLC 已停止。

用户界面只存在当前 ST Workbench；不复制并启动原 EcMotion.Hmi。复用的是 DXF 几何处理、路径资源协议、运动核心和反馈定义。硬件组态仍在当前自有硬件界面完成，EtherCAT 收发只由既有实时核心负责。

## 连续加工的含义与边界

导入点是几何描述，不是逐点 MoveAbsolute 命令。连续规划必须考虑前瞻、轴速度/加减速度、跃度、曲率、参与轴限位、段接点速度连续性和轮廓容差。原图直线、圆弧和圆应保留几何语义，不能仅按离散点数量宣称规划完成。

同一连续轮廓内按规划速度通过中间点；尖角如何通过受配置的几何容差与各轴动力学限制约束。零容差且几何尖角不允许改变时，转角处可能必须降至零速；不能承诺在任意尖角保持非零加工速度。不同轮廓之间的非加工连接必须显式定义，不能自动走刀跨越空白区域。路径下载不引起位移；启动后是否包含到起点的移动必须作为工程内明确的进入策略。

## 原项目可复用与需要新增的部分

- `EcMotion.Sdk/CadPathImporter.cs`：有界 ASCII DXF 解析，支持 LINE、ARC、CIRCLE、直线 LWPOLYLINE、2D/3D POLYLINE，拒绝不支持实体、bulge 和不适用法向，保留 XYZ。
- `EcMotion.Sdk/MotionPathBuilder.cs`、`EcMotion.Protocol/ProtocolMessages.cs`、`MainWindowViewModel.Paths.cs`：已有路径草稿、预存、明确版本引用、执行编号和进度。现有资源模式为 ExactStop，不能直接作为 Continuous 使用。
- 原实时核心与租约/回执通道可以继续作为执行基础。
- 新增：当前 ST 工程的路径资产持久化、路径编辑页、工程资源库动态路径条目、路径依赖清单、ST 可执行功能块、OpenPLC 扫描桥、连续规划及实时执行链。
- 原独立曲线规划内核尚未进入运行链，不能将其几何自测视为连续加工已经可用。必须补齐实际周期输出、约束和反馈验收。

## 验收顺序

先验证离线导入、保存重开、版本/哈希、轴映射和 ST 真实编译；再使用原生虚拟控制后端验证连续规划、周期输出、请求幂等、进度、停止/取消、断线及资产不匹配。最后在明确轴/驱动器配置后进行低速实机验收，包括持续轨迹、轮廓误差、时间连续性、跟随误差和故障停机。未通过实际执行链验证前，界面不能显示“可连续运行”或以模拟状态作为真实轴反馈。

本阶段不运行实体轴，不替换原项目界面，不默认重启已运行的控制器或抢占控制权。

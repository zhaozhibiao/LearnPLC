# 统一工程中的连续路径

2026-10-14 已实现工程路径管理、DXF 几何导入、保守连续规划、可编译 ST 功能块、候选包依赖与 Linux 虚拟执行桥。所有操作留在当前工程站，未复制第二套 HMI。**当前执行后端仅为 VirtualContinuous；尚未接入真实 EcMotion 核心的 Continuous 执行，不能驱动实体轴。**

## 使用

1. 保存并重新启动工程站，在“硬件与轴”配置 XY 或 XYZ 工程轴，单位 mm、位置限位；可填写速度、加减速度和跃度上限。
2. 工程树右键“路径资源”导入 DXF，中央原 ST 页切换到路径编辑内容，原顶栏与任务、连接、下载、在线页面保留。
3. 选择一条轮廓，填写 ST 名称、原始单位与转 mm 倍率、轴映射、偏移、速度、加减速、跃度及容差，点击预览/离线检查。蓝线是原几何，绿线是实际离线规划轨迹，黄色点是起点。
4. 点击预存，得到不可变的 ID/版本/摘要。保存 `.stproj` 时同时保存路径几何、导入参数和轴映射；预存新版本不会覆盖原版本。
5. 选择程序源文件，在右侧“工程路径”拖入具体版本或双击插入。自动声明 `MC_ExecuteContinuousPath` 实例与 Execute/Stop 信号，绑定明确的 ULINT PathId、ULINT Version 和完整 ContentHash；修改信号为工艺条件。实例按路径名生成，例如 `Contour_1`、`Contour_2`，自动避开已有实例和辅助变量。资源条目中的 `v1` 是路径预存版本，实例末尾 `_1` 是命名序号，两者互不影响。早期名称 `SnippetPath_<GUID>_v11` 的末尾是 `v1` 加实例序号 `1` 连写，并非版本 11；旧源码不自动改名。

“转 mm 倍率”支持正数或“目标:原始”比例：`1` 与 `1:1` 都乘以 1，`10` 与 `10:1` 都乘以 10，`1:10` 乘以 0.1。原始单位字段是备注，不自动换算坐标。修改倍率或运动参数会立即使旧规划时间失效；点击“预览 / 离线检查”后显示新的预计运动时间。输入无效、超出轴行程或规划预算时显示原因，不继续显示上次成功的时间。当前预备轨迹上限为 600 秒及 250000 个采样点；超限需要拆分轮廓或调整参数。修改草稿不覆盖已预存版本，应用到 ST 执行须预存新版本并更新调用。
6. 检查/编译与生成候选包都支持运动库。包内携带路径及准备好的连续轨迹、ST 库、原生桥、虚拟工作进程、许可证和校验清单。引用缺失、版本/摘要错误、动态未验证引用会被拒绝；功能块数组当前拒绝。
7. Linux 编译只在暂存版本中为 Runtime 入口添加生命周期钩子，原安装源码不改动。运动候选的激活要求显式配置且与候选清单匹配的私有 VirtualContinuous 工作者、运行环境与能力文件。编译结果会报告后端是否就绪；未配置时工程站显示“连续运动后端未就绪，不可激活”并禁用激活按钮，设备端也会再次核验。不会自行启动服务或抢占轴控制权。

工程示例：[Continuous.stproj](../examples/continuous-path/Continuous.stproj)。示例包含工程路径、两个逻辑轴和 ST 调用，供离线编译/隔离虚拟验证，不能直接作为现场程序激活。

## 实际实现边界

支持 ASCII DXF 的 LINE、ARC、CIRCLE、直线 LWPOLYLINE、2D/3D POLYLINE，保留原始线/圆弧和 XYZ。不同实体保持独立轮廓，未自动连接间隙或选择分叉；建议 CAD 中把需要一次执行的连通轮廓整理为 POLYLINE。bulge、样条、块、非默认法向等明确拒绝，不静默导入残缺图形。

准备阶段生成 C2 几何和统一起停时间律，通过控制多边形的导数上界保守限制合成加工速度、加减速度、跃度及各轴动态上限，控制多边形整体检查位置限位。连续几何中间点不逐点停止。零容差尖角、反向尖点和需要精确解析执行的零容差圆弧会拒绝，不能把它们偷偷圆滑或宣称任意尖角不停顿。全局保守缩放可能显著低于请求速度；参数是上限，不是保证达到的加工速度。离线准备限制：4096 资产段、50000 几何节点、250000 周期样本、600 秒；候选轨迹清单单文件上限 16 MiB，工程路径版本上限 64、内嵌资产总量 2 MiB。

原生扫描桥只有固定大小的锁自由单生产/消费队列和有限次复制，不在 PLC 扫描中做 Socket、文件解析、分配或线程创建。后台通信不能代替扫描心跳；扫描停止推进会触发工作进程超时。Execute 上升沿只提交一次；Stop 只由当前请求所有者断言并保持，不被其他实例清除。完成、故障和进度来自独立执行工作进程，界面不生成 Done。

在线路径页从同一份、已核对源程序/调试身份的变量监视中匹配 ID、版本和摘要，显示 RequestId、Execute、Busy、Done、Error、ErrorID 和 Progress。缺失/过期/断线明确显示不可用。预览是规划几何，不声称是实体轴位置轨迹。用户工程只有当前工程站一份资源配置；后台进程是执行分层，不是另一个工程。

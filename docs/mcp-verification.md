## 实际限制

- 工程工具编辑服务草稿，不实时修改桌面未保存缓冲；保存后须重新打开工程。
- 目前提供 stdio；只支持远程 HTTP 的客户端需要后续 HTTP 接入层。
- 硬件/网络/机械/周期参数仍是离线工程配置，不能解释为驱动或 Linux 调度已应用。
- 基础真实轴控协议与回执已实现，实体硬件尚未现场验收。实机连续轨迹、机械/旋转参数应用、定时速度运行及未确认的动态参数继续拒绝。
- 仿真 Jog 是设备租约约束的最大时间，不是精确轨迹时长；仿真成功不证明实体轴能力。

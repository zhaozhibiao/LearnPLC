# 在线 BOOL 单次写入

在线监视提供“修改变量（BOOL）”折叠区。普通采样和趋势仍只读；写入独立操作，每次确认，不持续强制。

## 试转操作

1. 重启工程站，打开 `examples/is620n-turn-test/TurnTest.stproj`，连接 Runtime。确保工程候选与设备活动程序一致、PLC已运行，再点击“开始监视”。RunOnce和ParametersConfirmed默认FALSE，PLC运行不会自动试转。
2. 在单次写入区选择 `Main.ParametersConfirmed`、值 `TRUE`，点击“写入一次”，核对确认窗口后提交，等待读回TRUE。
3. 确认现场可试转后，选择 `Main.RunOnce`、值 `TRUE`，点击“写入一次”并确认。这一步才会执行正转1.5圈、到位后等待2秒、反转1圈，最后停在起点+0.5圈并撤使能。

`CancelTest=TRUE` 请求普通控制停止。再次测试应先将RunOnce写回FALSE、确认停止，再复位程序结果；不会自动重试未知结果。

也可以直接在ST编辑器中右键变量名，选择“写入 TRUE 一次”或“写入 FALSE 一次”。菜单显示完整变量名和当前值，仍需在确认窗口提交；不会修改ST源码。声明与程序正文均可使用，注释、字符串、非BOOL及离线/过期变量不提供可执行写入。鼠标右键按实际点击位置解析，键盘菜单键按光标位置解析。

确认窗口支持调整大小，正文过长时滚动；确认和取消按钮固定在底部，不随正文滚出窗口。

## 写入规则

- 当前只支持源码中顶层PROGRAM的BOOL，排除AB内部桥变量和功能块嵌套字段；其他类型仍只读。
- 名称如Main.ParametersConfirmed，实际映射可能为INSTANCE0.PARAMETERSCONFIRMED。地址由匹配的编译调试映射提供。
- 写入前检查源码、候选、符号摘要、程序MD5、连接及采样时效；确认期间工程、连接、选择变化则不发送。
- Runtime只在PLC运行时接受请求。使用一次性软写入，不调用强制/解除强制接口，程序仍可覆盖该值。
- “已接受”只代表入队，后续新采样才是读回结果；不一致不能视为未执行并自动重试。
- 超时/断线后结果可能未知，绑定失效，需重新绑定并读取实际值；不自动重放。

## 实测

2026-10-20，192.168.1.31已升级接口，保留活动测试程序及原运行状态。实机仅将原本为FALSE的ParametersConfirmed单次写为FALSE并认证读回，未写TRUE、未触发试转。验证后RunOnce、ParametersConfirmed、Active均FALSE，轴Disabled、运动命令序号0。

## 在线监视界面

在线监视页提供“开始监视 / 断开监视”、变量实例树和趋势。选中数值变量查看趋势；刷新保留选择与展开状态。
需要写值时展开“修改变量（BOOL）”，选择变量和 TRUE/FALSE，再点击“写入一次”并确认。窄窗口内可滚动操作。
原始设备状态及日志查询位于“连接与工具 → 设备诊断”，默认折叠。

# 工程资源与指令库

保存并重新启动工程站后生效。工程树中右键点击实际资源，操作始终针对所点击对象。类别节点直接添加对应资源；程序、函数、功能块、数据类型和全局变量提供打开、添加、重命名、删除、属性。除全局变量外可复制资源并修改 POU 名称。全局变量直接复制会形成重名声明，因此需要通过“添加全局变量”建立新对象。任务引用中的程序不可删除；其他删除需要确认。属性显示类型、语言、源路径、声明接口与任务引用。

任务节点可添加未启用任务、重命名、修改周期和绑定程序；当前仍仅运行一个启用的周期任务。硬件节点右键进入自有 IO/轴配置页面。名称输入支持 Enter 确定、Escape 取消；默认资源名称自动避开重复项。右键当前资源保留光标与撤销记录。

右侧指令库在所有页面可见，宽度可通过中间分隔条调整。支持搜索名称、指令 ID、用途和分类。点击指令查看说明及代码预览；左键按住移动到 ST 代码行上松开插入，也可双击或点击“插入到当前光标”。模板在目标完整代码行之前插入，避免拆断现有语句；注释、字符串或跨行表达式内部拒绝插入并提示。拖到变量声明区域时执行调用移到代码段，实例声明加入目标 POU 的 VAR 区，没有 VAR 区时自动创建。变量名称自动去重；声明和调用作为同一撤销动作。插入修改源码并使原在线监视身份失效。

包含 30 个标准 ST 模板，以及按工程轴和预存路径生成的调用：

- 逻辑与门控：AND、OR、XOR、NOT。
- 流程与程序段：IF/ELSE、ELSIF、CASE 状态机、FOR、WHILE、REPEAT、注释分区、RETURN。
- 触发与锁存：R_TRIG、F_TRIG、SR、RS。
- 计时器：TON、TOF、TP；计数器：CTU、CTD、CTUD。
- 数值与比较：基础运算、范围判断、LIMIT、SEL、MIN/MAX、类型转换、ABS/SQRT。
- 字符串：LEN、CONCAT。
- 工程轴：配置轴后生成九种真实功能块调用，自动声明实例并绑定工程轴；未配置轴时显示配置提示和“配置工程轴”入口。旧的“待接入”注释模板已移除。
- 工程路径：导入并保存预存路径后，生成绑定路径 ID、版本和摘要的调用。

模板输入初始化为示例值，插入后必须替换为实际信号和参数。指令库提供编程辅助，不自动执行、下载或启停 PLC。

参考交互：[OpenPLC 工程树说明](https://edge.autonomylogic.com/docs/openplc-editor/workspace-overview/project-explorer/)；参考指令类别：[ABB 标准操作符与库元素](https://help.plc.abb.com/overview_operators_and_library_elements.html)。仅参考公开功能分类，未复制厂商代码、界面素材或商业库。

2026-10-14 验证：构建零警告/错误；核心测试覆盖声明位置、命名去重、多个 POU、完整语句、注释/字符串及跨行表达式；桌面测试覆盖实际右键目标、左键拖动起始、拖放事件与位置、搜索、复制、删除保护、单次撤销、重载对象身份。30 个标准模板通过独立真实 STruC++ 编译和 OpenPLC 候选包生成，7 个轴控注释示例不作为运动已实现的证据。桌面测试为 Avalonia Headless 指针和拖放路由验证，不包含 Windows 原生拖放驱动的人工验收。
